Rubi

Only what's precious stays in context. Rubi keeps Claude sessions short on its own, saves a handoff before every compaction and brings it back right after. You spend fewer tokens and never lose the thread.

Cost is in input-token equivalents (cache read 0.1×, cache write 1.25×, output 5×) using Anthropic's price ratios, so it holds for any model or plan. Across 30 days of real usage (284 sessions, short ones included), the measured saving was about one third.

How it works

Four hooks and a markdown vault. No server, no database, no dependencies beyond Node.

Compact early

Claude Code compacts on its own at 150k instead of near 1M. You never type /clear.

Meter

At 80% of the window, a hook tells Claude to save a handoff: goal, decisions, key files, next step.

Record

Right before compaction, Rubi writes what's about to vanish: your requests, files changed, commands run.

Restore

Right after, the handoff is injected back. Claude carries on from ~60k tokens instead of 500k+.

Install

Pick where you use Claude.

  1. Add and install the plugin inside Claude Code:
> /plugin marketplace add YURIBEDRAN/rubi
> /plugin install rubi@rubi
  1. Turn on early compaction and pick your vault folder:
$ git clone https://github.com/YURIBEDRAN/rubi && cd rubi
$ node scripts/instalar.mjs
  1. That's it. Work normally. Try /rubi:raio-x to see where your tokens go.
